# 슬라이드 자료 폴더

홈페이지 첫 화면의 슬라이드 6개가 배경으로 쓰는 사진·영상을 모아 둔 곳입니다.
폴더 하나가 슬라이드 하나입니다.

| 폴더 | 슬라이드 |
|---|---|
| `01-vision` | 01 비전 (Happy Healthy Church) |
| `02-worship` | 02 예배 안내 (Come And Worship) |
| `03-greeting` | 03 담임목사 인사말 (Walk With Jesus) |
| `04-people` | 04 섬기는 분들 (Serving Together) |
| `05-location` | 05 오시는 길 (Visit Us) |
| `06-history` | 06 걸어온 길 (Since 1989) |

## 배경 바꾸는 법

1. 바꾸고 싶은 슬라이드의 폴더에 사진(jpg, png 등)이나 영상(mp4, mov 등)을 넣습니다.
   파일 이름은 아무거나 괜찮습니다. 폴더에 여러 개가 있으면 **가장 최근에 넣은 파일**을 씁니다.
2. 터미널에서 프로젝트 폴더로 가서 아래 명령을 실행합니다.

   ```bash
   python3 update_slides.py
   ```

3. 브라우저에서 새로고침해 확인합니다.
4. 공개 사이트에 올리려면 커밋하고 푸시합니다. (Claude에게 "슬라이드 반영해서 배포해 줘"라고 하면 2~4를 대신 합니다.)

폴더를 비워 두면 그 슬라이드는 기본 그래픽으로 나옵니다.

## 알아둘 점

- `web.jpg`, `web.mp4` 는 스크립트가 만든 웹용 파일입니다. 지우거나 고치지 않아도 됩니다.
  원본은 그대로 두고, 사진은 긴 변 2400px JPG로, 영상은 소리 없는 720p로 변환합니다.
- 공개 사이트에는 `web.jpg`, `web.mp4` 만 올라갑니다. 원본 파일은 이 컴퓨터에만 남습니다.
- 영상은 소리 없이 자동 반복 재생됩니다. 슬라이드가 15초마다 넘어가므로 앞부분만 보입니다.
- 글자 색(흰색/남색)은 배경 밝기를 보고 자동으로 정합니다.
  직접 정하고 싶으면 그 폴더의 `options.json` 을 고칩니다.

  ```json
  {
    "tone": "dark",
    "dim": "soft",
    "position": "62% 45%",
    "alt": "사진 설명"
  }
  ```

  - `tone`: `dark` = 어두운 배경, 글자 흰색 / `light` = 밝은 배경, 글자 남색
  - `dim`: `soft` 로 두면 사진 위에 얹는 그늘이 옅어집니다 (`tone` 이 `dark` 일 때)
  - `position`: 화면에 맞춰 자를 때 중심으로 둘 위치 (가로% 세로%)

## 사진 여러 장을 카드로 늘어놓기

한 슬라이드에 사진 여러 장을 부채꼴 카드처럼 보여 줄 수 있습니다 .

1. 폴더에 사진을 2~5장 넣습니다. 이름순으로 왼쪽부터 놓입니다 (`1_...`, `2_...` 처럼 번호를 붙이면 순서를 정할 수 있습니다).
2. 그 폴더의 `options.json` 에 `"layout": "cards"` 를 적습니다.

   ```json
   { "layout": "cards" }
   ```

3. `python3 update_slides.py` 를 실행합니다.

세로로 긴 사진(4:5)이 가장 잘 맞습니다. `"layout"` 줄을 지우면 다시 사진 한 장 배경 방식으로 돌아갑니다.

## 사진 여러 장이 화면 가득 넘어가게 하기

사진이 천천히 확대되면서 다음 사진으로 넘어가는, 영상 같은 배경입니다 (지금 `06-history` 가 이 방식입니다).

1. 폴더에 사진을 2~12장 넣습니다. 이름순으로 나옵니다 (`01_...`, `02_...`).
2. 그 폴더의 `options.json` 에 `"layout": "slideshow"` 를 적습니다.

   ```json
   { "layout": "slideshow", "tone": "dark" }
   ```

3. `python3 update_slides.py` 를 실행합니다.

가로로 긴 사진이 잘 맞습니다. 사진 한 장은 3초씩 보이고, 슬라이드는 15초마다 다음으로 넘어갑니다.

### 사진마다 보이는 위치 조정하기

화면 비율에 맞춰 사진의 위아래(또는 좌우)가 잘립니다. 인물이 너무 위나 아래에 걸리면 `options.json` 의 `"focus"` 로 그 사진의 중심을 정합니다.

```json
{
  "layout": "slideshow",
  "focus": { "주일_설교": "80% 0%" }
}
```

- 왼쪽 값은 파일 이름의 일부, 오른쪽 값은 `가로% 세로%` 입니다.
- 세로를 `0%` 로 하면 사진의 윗부분이 남아 인물이 화면에서 **아래로** 내려오고, `100%` 로 하면 아랫부분이 남아 **위로** 올라갑니다.
